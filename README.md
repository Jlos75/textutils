# textutils
A lightweight Python library for common text-processing operations.

## Features
- Word counting
- Character counting
- Reverse the text
- Capitalize the text
- 
## Function name:
- word_count
- character_count
- reverse
- capitalize_words
- 
## Installation
Install the package from the project directory:

```powershell
python -m pip install .
```

For development and testing, install the optional development dependencies:

```powershell
python -m pip install -e ".[dev]"
```

The library has no runtime dependencies outside the Python standard library.
