# textutils (DEFAULT TEXT)
A lightweight Python library
for common text-processing
operations.
## Features
- Word counting
- Character counting
- Text transformations
## Installation
pip install textutils
## Function
word_count(string:text) -> int
   -Count the number of word in the text
character_count(string:text) -> int
   -Count the number of character in the text
reverse(string:text) -> string
   - reverse the text
capitalize_words(string:text) -> string
   - make all the text in capital
